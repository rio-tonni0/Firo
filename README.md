# 🌸 FloraVibe | Premium Flower Boutique

A modern, responsive front-end experience for a luxury flower shop. This project focuses on high-quality imagery, smooth transitions, and an intuitive shopping flow for floral enthusiasts.

---

## ✨ Features

* **Dynamic Gallery:** Dedicated styling for a beautiful flower showcase.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop views via `responsive.css`.
* **Smooth Animations:** Custom motion effects powered by `Animetion.css`.
* **Interactive UI:** Detailed sections for customer reviews, contact forms, and brand story.
* **Modular Styling:** Cleanly organized CSS files for easy maintenance.
